# DocumentReview

## DocumentReview

Обезличивание, повторная проверка и шлюз ревью входят в один устанавливаемый проект. Команда `document_review.cli` по умолчанию выполняет только локальную обработку. Qwen получает исходные абзацы и соответствующие им абзацы готовой копии, включая текст таблиц и колонтитулов. Ответ `{"safe": true}` означает, что модель пропустила документ. Он не гарантирует полного удаления персональных данных.

```powershell
cd C:\VolgaAsk\DocumentReview
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m document_review.cli "C:\путь\заявление.docx"
.\.venv\Scripts\python.exe -m pytest -q
```

Для внешнего анализа задай ключ авторизации в переменной окружения `GIGACHAT_CREDENTIALS`. Переменная `GIGACHAT_SCOPE` определяет тип доступа (по умолчанию `GIGACHAT_API_PERS`), `GIGACHAT_MODEL` — модель (по умолчанию `GigaChat`), `GIGACHAT_CA_BUNDLE` — необязательный путь к доверенной цепочке сертификатов в формате PEM. Проверка TLS включена. Для реальных студенческих документов предварительно установи допустимость передачи и достаточность защиты.

Флаг `--allow-external` разрешает передачу конкретной проверенной копии в GigaChat. Юридическая и бухгалтерская проверка выполняются вместе. В промпте запрашивается ответ до 100 слов из трёх пунктов: ошибки, исправления и итог. Пример совмещённого анализа синтетического документа:

```powershell
.\.venv\Scripts\python.exe -m document_review.cli "C:\путь\пример.docx" --allow-external
```

После проверки сервис отправляет байты этой же копии под именем `anonymized.docx`, получает отчёт и запрашивает удаление вложения даже при ошибке анализа. При потере связи подтверждение загрузки или удаления может не прийти. В таком случае проверь хранилище GigaChat. Запрос на удаление вложения не определяет сроки хранения данных самим провайдером.

В Python используй `DocumentReviewService().check(source)` или `DocumentReviewService().review(source, allow_external=True)` из пакета `document_review`. Метод ревью возвращает строку с замечаниями. Обмен между этапами идёт в памяти процесса. Ниже описан отдельный сценарий выдачи локальной копии по временной ссылке.

Модуль принимает путь к DOCX, ссылку `file://` или прямую ссылку HTTP(S). Локальная Ollama находит персональные данные и предлагает вымышленные замены. Для распознаваемых телефонов, длинных номеров и электронной почты дополнительно используется поиск по формату. Одинаковые фрагменты получают одну замену в пределах обработки.

## Запуск

Нужны Python 3.11+ и запущенная Ollama с моделью `qwen2.5:3b`. Из папки DocumentReview выполни:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m document_review.anonymize_cli "C:\путь\заявление.docx" --ttl 300
```

CLI печатает ссылку для скачивания и обслуживает её до истечения срока. Адрес модели и имя задаются переменными `OLLAMA_HOST` и `OLLAMA_MODEL`.

## Использование из Python

```python
from document_review.anonymizer import DocumentAnonymizer

with DocumentAnonymizer(ttl_seconds=300) as service:
    url = service.anonymize("http://localhost:8000/documents/input.docx")
    print(url)
    input("Нажми Enter для завершения выдачи")
```

Для интеграции создай экземпляр при запуске приложения и вызови `close()` при остановке. Результат `anonymize(source)` — строка URL. Локальный потребитель получает байты DOCX обычным GET. Ссылка доступна на том же компьютере в течение заданного срока, по умолчанию пять минут. После истечения срока сервер отвечает 404. Копии хранятся в памяти, закрытие экземпляра отзывает все его ссылки. Скачанные потребителем файлы имеют собственный срок хранения.

## Содержимое копии

Выходной файл заново собирается из текста, абзацев, таблиц и колонтитулов. Копия предназначена для текстового ревью. Оформление упрощается. Исходные свойства файла, комментарии, удалённые правки, ссылки на внешние ресурсы, вложения и изображения исключаются. Сканы требуют отдельного OCR. Максимальный размер входного файла — 16 МиБ.

Распознавание зависит от локальной модели. Редкие ФИО, написанные иначе варианты имени и косвенные признаки личности могут остаться в тексте. Для конфиденциальных документов перед внешней передачей проверь копию.
