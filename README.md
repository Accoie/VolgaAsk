# VolgaAsk

Чат-помощник Волгатеха: отвечает на вопросы по документам университета и помогает оформлять заявления.

## Сервисы

| Путь | Назначение |
|---|---|
| `Frontend/` | Веб-интерфейс чата, истории и управления документами |
| `Backend/` | ASP.NET Core API, учётные записи, чаты и маршрутизация запросов |
| `RagService/` | Поиск по базе знаний и генерация ответов |
| `DocumentIndexer/` | Обработка, проверка и индексация PDF |
| `DocumentActualizer/` | Обновление каталога документов с сайта университета |
| `DocumentGenerator/` | Диалоговое заполнение и создание DOCX |
| `DocumentReview/` | Проверка и анализ готовых документов |

Сервисы запускаются через Docker Compose из корня репозитория.

## Быстрый запуск

1. Создайте `.env` на основе `.env.example` и задайте пароли приложения, базы знаний и администратора.
2. Запустите контейнеры:

   ```powershell
   docker compose up -d --build
   ```

3. Откройте [чат](http://localhost:8080) или [Swagger API](http://localhost:8080/swagger).

Для компьютера без NVIDIA можно запустить Compose с CPU-конфигурацией:

```powershell
docker compose -f docker-compose.yml -f compose.cpu.yml up -d --build
```

Для первого запуска нужны интернет и свободное место для образов и моделей. Настройки и пароли храните в `.env`, не добавляйте его в Git.

## Возможности

- `User`: задавать вопросы, создавать и просматривать собственные чаты.
- `Employee`: управлять документами базы знаний.
- `Admin`: дополнительно управлять учётными записями и ролями.
- Сотрудники и администраторы могут добавлять документы и настраивать шаблоны через раздел **Управление документами**.
- Чат помогает заполнить заявление, формирует DOCX и позволяет просмотреть, скачать или доработать документ.

Подробности о сервисах и их настройке описаны в README соответствующих каталогов.
